# 🏴‍☠️ One Piece Episode Manager CLI

A simple CLI tool that launches a local web app to help you manage and track your One Piece episodes.

When you run the CLI, it automatically starts a server and opens a webpage at:
```bash
http://localhost:3000
```

## 🚀 Installation

Clone the repository and set it up locally:
```bash
git clone https://github.com/OgunwandeBukunmi/onepiece_episode_manager_cli.git
cd onepiece_episode_manager_cli
npm install
```

# 🔧 Setup (CLI)

Make the CLI executable and link it globally:
```bash
chmod +x cli.js
npm link
```
